# Claude Prompt Libraries: 프롬프트 3곳으로 클로드 화면 뽑기

검증: 2026-11-08. 릴스(@ai.yeongseon, 2026-11-01)와 DM 가이드북(AINOW, 2026-10-23) 대조 확인. 세 곳 모두 실재한다. 아래는 가이드북의 방법을 내 말로 정리한 것이고, 프롬프트 1·2·3과 A~D의 원문은 가이드북 링크에 있다.

## 세 곳 한눈에

| 곳 | 무엇을 주나 | 얼마나 | 돈 |
| --- | --- | --- | --- |
| Awesome Opus 5.5 Videos | 사람들이 Opus 5.5로 만든 화제 영상 + 그때 쓴 프롬프트 | 프롬프트 703개 | 무료 (GitHub, MIT) |
| VibePrompt | 홈페이지 칸(첫 화면·가격표·FAQ…)마다 쓸 디자인 지시문 + 완성 코드 | 지시문 286개 · 분류 15개 | 무료 |
| Motion | 마우스를 따라 움직이는 화려한 섹션의 긴 프롬프트 | 섹션 54개 | 일부 무료 (무료 칸 9개, 2026-10-23 기준. 나머지 월 9달러부터) |

주의: 릴스의 "싹 다 무료"는 Motion에 안 맞는다. 무료 칸만 무료고, 나머지는 유료(월 9달러 / 평생 99달러, 10월 25일 이후 149달러 / Studio 249달러)다. 유료 칸은 사용자가 정하기 전엔 쓰지 않는다.

## 자동 적용 — 웹덱·랜딩 HTML을 만들 때

사용자가 라이브러리 이름을 말하지 않아도 적용한다. **HTML 웹덱·홈페이지 히어로·랜딩 섹션을 만드는 작업에서는 Claude가 아래 세 곳에서 맞는 프롬프트를 골라 자동 참조한다.** 편집 가능한 PPT(.pptx) 납품본에는 쓰지 않는다 — 그쪽은 `ppt` 스킬의 수제 파이프라인이 정본이고, 이 라이브러리는 HTML 산출물 전용이다. Motion 유료 칸은 사용자 결정 전 사용 금지.

## 공통 사용법 5단계

세 곳의 차이는 '무엇을 만드느냐'뿐이고, 쓰는 순서는 똑같다.

1. **고르기** — 사이트에서 마음에 드는 걸 하나 고른다. 처음엔 단순한 것부터. 제일 화려한 것부터 고르면 오래 걸린다.
2. **복사** — 프롬프트 글을 통째로 복사한다. 일부만 복사하면 결과가 엉뚱해진다.
3. **붙이고 한 줄** — 클로드에 붙인 뒤 원하는 조건을 한 줄 덧붙인다. 조건 없이 붙이면 영어 화면, 여러 파일로 나오기 쉽다.
4. **열어 보기** — 미리보기 창 확인, 또는 HTML 파일 더블클릭. 파일을 메모장으로 열면 글자만 보인다. 크롬으로 연다.
5. **고쳐 달라기** — "글자 더 크게"처럼 말로 고쳐 달라고 한다. 한 번에 여러 개를 고치라고 하면 다른 데가 망가진다.

붙일 때 덧붙이는 한 줄 4개 (필요한 것만 골라도 된다):
- 결과는 HTML 파일 하나로, 파일만 열어도 바로 보이게.
- 화면 글자는 전부 한국어로.
- 휴대폰 화면에서도 깨지지 않게.
- 필요한 라이브러리는 인터넷 주소(CDN)로 불러오게.

## 1. Awesome Opus 5.5 Videos — 화제 영상 따라 만들기

- 주소: github.com/yihui-dev/awesome-opus5-5-videos (MIT, 별 7.2천)
- 분류 4개: Motion graphics · Explainers · 3D scenes · Games & interactive
- 쓰는 법: 마음에 드는 영상 아래 Prompt 링크 → `## Prompt` 칸의 글만 복사 → 클로드에 프롬프트 1(가이드북)과 함께 붙이기. 9:16 세로 15초 안팎이 기본, 가로가 필요하면 16:9로 바꾼다.
- 고를 때 팁: Prompt 칸이 긴 것이 원본과 비슷하게 나온다. '일부만 공개(partial)'라고 적힌 파일은 처음엔 피한다.
- 꼭 지킬 것: 영상과 프롬프트의 주인은 만든 사람이다. 따라 만든 영상을 올릴 땐 원작자 계정을 함께 적는다. Skillry(skillry.dev)는 저장소 운영자의 비교 사이트고, 원본은 각 프롬프트 파일의 'Original post'에서 본다.
- 모델은 Opus 5.5로. 다른 모델로 하면 결과가 많이 달라질 수 있다.

## 2. VibePrompt — 홈페이지 칸 쌓기

- 주소: vibeprompts.dev (무료)
- 홈페이지는 위에서부터 '칸'을 쌓은 구조다. VibePrompt는 칸마다 쓸 디자인 지시문을 분류해 둔 곳이다.
- 쓰는 법: 분류에서 Hero(첫 화면) 고르기 → 마음에 드는 미리보기 View → Prompt 탭에서 Copy → 클로드에 프롬프트 2(가이드북)와 함께 붙이기. Tailwind·JavaScript 탭은 완성 코드라 안 써도 된다.
- 처음이면 첫 화면 → 가격표 → FAQ 세 칸만. 두 번째 칸부터는 "방금 만든 페이지 아래에 이 칸을 이어 붙여줘"라고 하면 한 파일로 쌓인다.
- 좋은 점: 지시문이 '무엇을 어디에 놓을지'까지 아주 구체적이다. 가격표 지시문에는 슬라이더 위치, 금액 계산 방식, 버튼 문구까지 적혀 있다.

## 3. Motion — 무료 칸으로 움직이는 첫 화면

- 주소: motionin.design (일부 무료)
- 쓰는 법: 갤러리 위 Free 버튼 → 무료 칸만 모아 보기 (10월 23일 기준 9개) → 카드 하나 클릭해 마우스를 올려 보고 → Copy Prompt 버튼 → 클로드에 프롬프트 3(가이드북)과 함께 붙이기. 프롬프트가 아주 길어도 통째로 쓰는 게 맞다.
- 처음 써 보기 좋은 무료 칸: Membrane(마우스를 따라 표면이 출렁임), Liquid Type(글자가 물처럼 움직임), Drag Gallery(끌어서 넘기는 사진첩).
- 무료 칸을 회사 일에 쓸 땐 사이트 안내를 한 번 확인한다. 유료 요금제는 상업·고객 작업에 쓸 수 있다고 안내돼 있다.

## 셋을 이으면 — 홈페이지 한 장 완성

같은 대화창에서 아래 순서대로 보내면 된다. 앞에서 만든 페이지를 클로드가 기억하고 있어서, 새 대화창을 열면 처음부터 다시 해야 한다.

- **A · 뼈대 (VibePrompt 3칸)**: 첫 화면 → 가격표 → 자주 묻는 질문 순서로 한 장짜리 홈페이지. HTML 파일 하나, Tailwind는 CDN으로, 글자는 한국어로.
- **B · 첫 화면 교체 (Motion 무료 칸)**: 방금 만든 페이지에서 첫 화면만 움직이는 섹션으로 바꾼다. 나머지 칸은 그대로 두고, 문구는 원래 첫 화면 문구를 쓴다.
- **C · 소개 영상 (Awesome)**: 프롬프트로 짧은 소개 애니메이션을 만들어서 가격표 바로 위에 넣는다. 가로 16:9, 10초 안팎, 자동 재생 후 반복.
- **D · 인터넷에 올리기 (선택)**: Vercel에 올려서 인터넷 주소를 만든다. Vercel 무료 요금제(Hobby)는 개인·비상업용이다. 회사·고객 사이트는 유료 요금제를 본다. Claude Code를 쓰면 올리는 과정까지 대신 해 준다.

## 만든 화면을 영상 파일로 뽑기

클로드가 만드는 건 '움직이는 웹 화면'이다. 릴스나 쇼츠에 올리려면 화면을 녹화해서 영상 파일로 만들면 된다.

| | 윈도우 | 맥 |
| --- | --- | --- |
| 전체 화면 | F11 | Ctrl + Cmd + F |
| 녹화 시작 | Win + Alt + R (Xbox Game Bar) | Shift + Cmd + 5 → '전체 화면 기록' → 기록 |
| 녹화 끝 | Win + Alt + R 한 번 더 | 메뉴 막대의 정지 버튼 |
| 저장 위치 | 동영상 > 캡처 폴더 (mp4) | 바탕화면 (mov) |

- 녹화 시작 직후 F5(새로고침)를 누르면 영상이 처음부터 다시 나온다.
- 마우스 커서가 찍히는 게 싫으면 화면 구석으로 옮겨 둔다.
- 윈도우 녹화는 열려 있는 창 하나만 찍힌다. 크롬 창을 클릭해 둔 상태에서 단축키를 누른다.

## 막힐 때

결과가 이상하게 나와도 대부분 한 줄이면 해결된다. 같은 대화창에서 오른쪽 문장을 그대로 말해 본다.

- 영어 화면이 나왔다 → "화면 글자는 전부 한국어로 바꿔줘"
- 여러 파일로 쪼개졌다 → "결과는 HTML 파일 하나로 만들어줘"
- 휴대폰에서 깨진다 → "휴대폰 화면에서도 깨지지 않게 해줘"
- 라이브러리 오류가 난다 → "필요한 라이브러리는 인터넷 주소(CDN)로 불러와줘"
