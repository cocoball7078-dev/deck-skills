# 원포인트 전략 프레임워크 (One Point Strategy)

## 출처와 성격

- 원포인트전략 「전략클래스」(18년차 전략담당 임원의 10회 과정, 인스타그램 @one_point_strategy, onepointstrategy.com)의 공개 페이지와 무료 공개된 강의록 1회차 미리보기에서 **공개된 프레임워크 체계와 핵심 명제를 재구성**한 것이다. 강의록 본편(1~9회차)은 유료 지적재산(워터마크)이므로 본편 원문을 인용·복제하지 않는다. 이 스킬은 구조와 개념의 정리이며, 상세 해설이 필요하면 사용자가 소장한 강의록을 참조한다.

## 핵심 명제

1. **방향이 속도보다 먼저다.** 일을 잘하는 것은 빠른 실행이 아니라 바른 방향의 문제. AI가 실행(조사·요약·초안·분석 시각화)을 대신하는 시대에, 여전히 사람 몫인 것은 네 가지다 — 무엇을 어떻게 시킬지 정하기 / 수많은 답 중 단 하나 고르기 / 내 판단 논리를 설명하기 / 결정하고 결과까지 책임지기.
2. **전략적 사고 = 지금 나에게 가장 유리한 방향에 대한 궁리.** 프레임워크는 필요할 때 찾아보는 지식이 아니라 머릿속에 장착해 두는 '생각의 출발점'이다. 장착되면 어떤 문제에서도 "이건 내부자원 이슈인가, 외부환경 이슈인가, 우선순위 이슈인가"로 즉시 구조화가 시작된다.
3. **큰 줄기는 지피지기 백전불태(知彼知己 百戰不殆).** 백전불패가 아니다 — 이길 가치 있는 싸움에서는 질 수도 있다. 백전불태는 "싸우는 내내 위태롭지 않은 상태", 즉 결과만큼 준비와 과정이 중요하다는 뜻이다.
4. **논리적이되, 논리에 매몰되지 않기.** 논리 프레임워크는 전략 프레임워크를 작동시키는 원리다. 사실에서 결론으로 갈 때 평균적인 해석(맥킨지 구름-비-우산: 먹구름→비→우산)에 머물지 않고, 내 상황과 목적을 먼저 넣어 평균 밖의 결론·기회(먹구름→파전집이 잘 되겠다)까지 도출하는 것이 Fact to Insight다.

## 문제 해결의 기본 흐름 (1회차 원리)

1. **핵심 문제 정의** — As is & To be의 본래 목적은 현황/목표 표가 아니라 핵심 문제를 정의하는 것이다.
2. **문제와 문제점을 구분한다** — 문제 = 해결 대상인 이미 발생한(할) 결과. 문제점 = 그 문제를 일으킨 원인. 핵심 문제는 하나여도 문제점은 여럿이다.
3. **문제점을 해결 가능성으로 나눈다**
   - 해결 가능 → **해결책**에 집중 (우선순위에 따라).
   - 해결 불가능 → 다시 예방 가능 여부로 나눠 **예방책**(비용 감수 시 상당 부분 예방)과 **회피책**(더 큰 비용으로 상황 자체를 회피)을 함께 궁리한다. 비용 순서는 대개 해결 < 예방 < 회피.
4. **지피지기 분석** — 해결책은 외부 환경(지피: 내 일에 영향을 미치는 모든 것)과 내부 역량(지기: 내 일에 쓸 수 있는 모든 가용자원)으로 나눠 분석한다.
5. **백전불태 전략** — 아래 세 전제를 **동시에 병렬로** 굴린다. 하나만 보면 실패한다.
   - ① 당장의 경쟁우위 확보 (경쟁우위는 늘 '일시적'이다. 안심하고 고객만족 노력을 멈추는 순간 수명주기가 꺾인다)
   - ② 우선순위 의사결정 (더 중요한 일에 집중하느라 작은 불을 잠시 방치할 수는 있으나, 방치가 큰 불이 되는 것은 경계. 자원 분산과 방치 사이에서 판단)
   - ③ 지속성장 (제품·사업은 늙고 경쟁자는 늘어난다. 매출 증가율이 꺾이기 **전에** 신제품·신사업이 나와야 하며, 개발 리드타임을 감안하면 둔화 조짐이 보일 때 시작해도 늦다)

## 16개 프레임워크 지도

### 논리 프레임워크 5종 (작동 원리 · 2~3회차)

| 프레임워크 | 용도 |
|---|---|
| As is & To be | 핵심 문제 정의 (현황→미래 표로만 쓰는 것은 오용) |
| MECE | 중복 없이, 누락 없이 나누기 |
| Logic Tree | 끝까지 파고들어 원인을 구조화 |
| Fact to Insight | 사실 → 내 상황·목적 반영 → 평균 밖 인사이트·기회 |
| 8 Matrixes | 구조화 사고를 위한 8가지 매트릭스 사고법 |

### 전략 프레임워크 11종 (지피지기 백전불태 스토리라인 · 4~9회차)

**지피 知彼 — 내 일에 영향을 미치는 모든 것 (외부 분석, 4회차)**
- **SWOT (재발견)** — 내외부를 잇는 종합 정리. 나열이 아니라 전략 도출로 연결
- **5 Forces** — 경쟁자·공급자·고객(구매자)·대체재·신규 진입자. "내 편인 줄 알았던 공급자가 더 무서울 수 있는 이유"처럼 이해관계자의 힘을 읽는 도구. 내 일의 이해관계자 파악에도 그대로 적용
- **PESTEL** — 거시 환경(정치·경제·사회·기술·환경·법규)으로 숲 보기

**지기 知己 — 내 일에 활용할 수 있는 모든 것 (내부 자원, 5회차)**
- **PQC** — 모든 비즈니스의 생존 법칙. Price(가격)·Quality(품질)·Convenience(편의) 중 무엇으로 승부할지, 각 요인의 강도와 실현 가능성을 따진다
- **VRIO** — 가치·희소성·모방 곤란성·조직 활용으로 자원의 전략적 강약점을 객관화

**백전불태 百戰不殆 — 경쟁우위부터 지속 성장까지 (6~9회차)**
- **본원적 경쟁전략 (6회차)** — 차별화·원가우위·집중화. 모든 의사결정의 기준이자 원칙. 단, 차별화를 시도조차 하면 안 되는 경우도 있다
- **STP 재정의 + RFM (7회차)** — Segmentation·Targeting·Positioning을 전략적으로. 누구에게나 매력적인 고객은 그만큼 선택받기 어렵다 — 현실적인 타겟팅이 핵심. RFM(최근성·빈도·금액)으로 체리피커마저 충성 고객(VVIP)으로 육성
  - Positioning 점검 4요소 (ESFJ 비유): **E** 사회적 증거(Social Proof) · **S** 본질적 강점(Core Strength) · **F** 반전 매력(Unexpected Appeal) · **J** 계획·통제 가능성(Planning & Control)
- **BCG 매트릭스 + 맥킨지(GE) 매트릭스 (8회차)** — 현실적 제약을 인정하는 우선순위 의사결정. 사업·제품 포트폴리오를 넘어 개인의 커리어, 리더의 조직관리에도 같은 원리로 적용
- **앤소프 성장 매트릭스 (9회차)** — 지속 성장의 도구. 기존 제품·사업에 쓴 자원을 레버리지 삼아 새 제품·사업을 만드는 6가지 길

### 과정 구조 요약 (10회차)

1회차 전략의 이해·전략가 마인드셋·손익 최적화·리스크 매니지먼트 → 2~3회차 논리 프레임워크 → 4회차 지피 → 5회차 지기 → 6회차 경쟁전략(원칙) → 7회차 STP·RFM → 8회차 우선순위 매트릭스 → 9회차 앤소프 → 10회차 랩업.

## 상황별 프레임워크 선택 가이드

| 상황·질문 | 꺼낼 프레임워크 |
|---|---|
| 문제가 뭔지부터 모호하다 | As is & To be로 핵심 문제 정의 |
| 보고·발표를 "간단히 자세하게" 하라 한다 | MECE + Logic Tree로 구조화, Fact to Insight로 결론 |
| 이해관계자·경쟁 구도가 복잡하다 | 5 Forces |
| 거시 변수(규제·경기·기술 변화)가 변수다 | PESTEL |
| 가진 자원을 다 파악·활용 중인지 의문이다 | VRIO + PQC |
| 우리 사업의 승부처를 정해야 한다 | PQC + 본원적 경쟁전략 |
| 제안·상품의 포지셔닝을 점검한다 | STP + 포지셔닝 4요소(E·S·F·J) |
| 사업·제품·일정·관계의 우선순위를 정한다 | BCG · 맥킨지 매트릭스 |
| 신사업·신제품 아이디어의 틀이 필요하다 | 앤소프 매트릭스 (기존 자원 레버리지 6길) |
| 리스크에 대비해야 한다 | 문제점 분해 → 해결책/예방책/회피책 분기 |
| 기업 분석(투자 포함) | 5 Forces로 산업구조 → PQC로 요인별 강도·실현 가능성 → 후속 분석 제안 |

## 실무 체크리스트 (워크시트 6종에서 도출)

1. **내 할 말 리스트** — 보고·회의 전 10분, 할 말을 리스트로 정리하고 들어간다 (끌려다니지 않는 법)
2. **손익 최적화 회고** — 결과만이 아니라 과정의 손익(얻은 것·치른 비용·부산물 By-product)까지 회고한다. 부산물을 고려하는 것이 차별점이다
3. **전략가 마인드셋 체크리스트** — 방향 궁리를 실행 전에 했는지 자가진단
4. **리스크 매니지먼트 체크리스트** — 해결 불가능한 문제점의 예방책·회피책을 미리 챙긴다
5. **전략적 자기소개 3단계** — 네트워킹에서 포지셔닝 4요소로 나를 소개
6. **성장 태도** — 누구나 하면 좋은데 비효율이라 안 하는 일을 기꺼이 감수하는 것이 성장의 트리거 (예: 회의 발언 전부 받아 적기)

## 적용 규칙

- **회의·보고 요약의 '한 장 지도' 방식**: 핵심 문제 / 문제점들 / 각각의 처리 방향(해결·예방·회피) / 지피지기·백전불태 요인 중 특히 중요한 것을 짚어 요약하면 전달력과 이해도가 함께 오른다.
- **AI에게 분석을 시킬 때**: 프레임워크를 명시해 지시한다. 예) "이 기업에 영향을 미칠 외부 요인들을 5 Forces 관점으로 분석하고, 각 요인이 PQC 중 무엇과 가장 밀접한지, 강도와 실현 가능성은 어떤지, 어떤 후속 분석이 유용할지 함께 제시해줘." 구조를 지정하면 평균적인 답이 아니라 판단 가능한 답이 나온다.
- **제안서·컨설팅 덱과의 연결**: 스토리라인을 지피(외부 환경·경쟁) → 지기(내부 자원·역량) → 백전불태(경쟁우위·우선순위·성장) 줄기로 잡으면 consulting-deck·mbb-slides의 액션 타이틀 구조와 자연스럽게 맞물린다.
- **우선순위 판단이 필요할 때**: "더 중요한 일에 집중하느라 방치된 작은 불인가, 아니면 커지기 전에 꺼야 할 불인가"를 명시적으로 묻는다.

레퍼런스의 출처 경계: 원포인트전략 고유 해석은 공개 페이지·1회차 미리보기 공개 범위만 반영했고, 프레임워크 본체 지식은 공개된 원전·표준 문헌(Porter, Barney, Kotler, Minto 등)을 웹 리서치로 확인해 재구성했다. 고유 패키징(8 Matrixes 세부 목록, 앤소프 6가지 비책 등 비공개 내용)은 일반론으로 대체하고 그 사실을 각 파일에 명시했다.
