# 막힐 때 꺼내 쓰는 컬러 꿀조합 + AI 프롬프트

검증: 2026-11-11. 릴스(@ai_surfer_club, 2026-10-25) 캡션·썸네일 직접 확인, 크리에이터 웹 검색, **원본 노션 가이드 전문 확인 완료**(사용자 제공 링크, 브라우저로 끝까지 읽음). 아래 조합 3종·색상 코드·역할·활용은 원본 가이드 내용이다. 미드저니 프롬프트 전문은 원본 가이드에 있으니 스킬 파일에 그대로 복사하지 않고 아래 링크에서 확인한다.

## 자동 적용 — 사용자가 색을 지정하지 않을 때

이 조합은 사용자가 "골라줘"라고 말할 때만 꺼내는 게 아니다. 덱·포스터·썸네일·웹 화면을 만드는 작업에서 **색 방향이 정해져 있지 않거나 막히면, Claude가 아래 3종 중 맥락에 맞는 조합을 골라 적용하고 어떤 조합을 썼는지 알린다.**

- 우선순위: 브랜드·템플릿 표준 색(제안서 Noto Sans KR 템플릿, nextHRD 로고 색 등)이 있으면 그게 정본이고 이 조합은 쓰지 않는다. 이 조합은 표지 비주얼·포스터·이미지 생성처럼 표준 색이 없는 자리의 것이다.
- 덱에서는 `ppt` 스킬이 이 스킬을 연동한다. 표지·이미지 장표의 색을 잡을 때 자동 참조한다.
- HEX 정확도가 필요한 자리(인쇄·브랜드 확정 색)에서는 생성 이미지가 아니라 컬러카드 HEX 값을 기준으로 지정한다.

## 원리 — 2색이 밋밋할 때 3번째 색 하나가 인상을 바꾼다

아이디어가 막힐 때 AI에 어렴풋한 느낌을 색으로 던져 본다. 두 가지 색은 마음에 드는데 어딘가 밋밋할 때, 세 번째 색 하나를 더하면 시안의 인상이 크게 바뀐다. 색 하나를 더했을 때 분위기가 어떻게 달라지는지 비교해 보는 게 이 가이드의 핵심이다.

## 쓰는 법 — 원본 가이드 순서

1. 마음에 드는 조합을 고른다.
2. 조합 아래 컬러카드 3개로 색과 역할을 확인한다.
3. 프롬프트를 복사해 미드저니에서 생성하고 색의 분위기를 비교한다.
4. 룩이 마음에 들면 상세 수정은 GPT·나노바나나 프로에서, 정확한 색은 포토샵에서 맞춘다.

주의: **미드저니는 HEX 값을 정확히 재현하지 못하고 글자도 부정확할 수 있다.** 색이 정확하게 나와야 한다면 ChatGPT(GPT)에서 생성하거나, 결과 이미지를 포토샵에서 수정한다. 미드저니는 멋진 룩을 잡는 데 쓰고, 상세 수정은 ChatGPT·나노바나나 프로에서 이어간다. 색 확인은 컬러카드(원본 HEX 값)를 기준으로 한다. 이미지 속 색은 생성 과정·조명·재질에 따라 달라질 수 있고, 프롬프트는 같은 방향을 탐색하는 출발점이지 동일 결과를 보장하지 않는다.

## 원본 조합 3종 — 색상 코드·역할 포함

### 01 · Creative Momentum — 장난스러운 발랄함 · 크리에이티브

- 라벤더 `#CBB3E8` · 배경 · 튜브
- 차트리즈 `#D4FF3F` · 궤도 · 구체
- 토마토 레드 `#E34234` · 포인트 · 주인공 오브제
- **추천 활용** · 크리에이티브 에이전시 · 신규 캠페인
- 포인트: 2색(라벤더 배경 + 토마토 레드)만 쓰면 밋밋하다. 차트리즈는 구와 궤도 같은 작은 부분에만 조금 넣어 장난스러운 리듬을 만든다. 양 조절이 핵심이다.

### 02 · Sound Waves — 신나는 발사 · 사운드

- 아이보리 `#FFFBEF` · 배경 · 메인
- 하늘색 `#90E0E8` · 두 번째 메인 · 파이프라인
- 빨간색 `#E63946` · 포인트 · 로켓 노즐
- **추천 활용** · 소셜 미디어 · 커뮤니티
- 포인트: 빨간색은 로켓 하단·기둥 트임 같은 포인트에만 쓴다. 포인트 색 하나만 바꿔도 이미지가 완전히 바뀌니, 한 컬러 값만 바꿔 보면서 비교한다.

### 03 · Sunburst Glow — 상큼한 생기 · 뷰티

- 아이보리 `#F5EFE6` · 배경 · 썬버스트(메인)
- 오렌지 `#FF5A1F` · 포인트 · 썬버스트 중심
- 버블검 핑크 `#D97F8C` · 포인트 · 제품 라벨
- **추천 활용** · 스킨케어 · 뷰티
- 포인트: 강한 오렌지 썬버스트에 분홍을 더하면 상큼하고 생기가 돈다. 다만 분홍은 제품 라벨에만 소량으로 — 오렌지의 세련된 느낌을 유지하고 분홍은 살짝 포인트로만 존재해야 한다. 색 잠금: 아이보리 주도, 오렌지는 중심에만, 분홍은 라벨에만.

## 팔레트 짜는 법 — 역할 4개, 총 3~4색

- **배경** 1색: 화면의 60%. 가장 넓게 깔리는 색.
- **메인** 1색: 주인공 오브제·타이틀의 색. 30%.
- **포인트** 1~2색: 강조할 때만 쓰는 색. 10%.
- **텍스트**: 배경과 대비되는 색 1개(화이트 또는 잉크 블랙). 작은 글씨가 읽혀야 한다.
- 총 3~4색으로 제한한다. 5색이 넘어가면 산만해진다.

## AI 프롬프트에 색 넣는 법

원본 가이드의 각 조합마다 미드저니 프롬프트가 있다. 전문은 노션 가이드에서 확인한다(아래 링크). 구조만 요약하면: [주제 + 스타일 + 색 이름·HEX·역할 + 질감·무드 + 비율·버전 옵션]이다. 예시로 01번 조합을 ChatGPT·미드저니에 넣는 법:

```
// 붙여넣기 — ChatGPT 이미지 생성

[주제]를 크리에이티브 에이전시 스타일 포스터로 만들어줘.
컬러 팔레트: 배경 라벤더 #CBB3E8, 궤도·구체 차트리즈 #D4FF3F, 포인트 토마토 레드 #E34234.
총 3색, 모두 평면. 그라데이션 금지. 세로 4:5.
```

```
// 붙여넣기 — Midjourney

[주제] poster, creative agency style, lavender background #CBB3E8, chartreuse accents #D4FF3F, tomato red focal object #E34234, flat colors, no gradients, bold geometric shapes --ar 4:5 --v 7.0 --style raw --chaos 5
```

- ChatGPT 이미지 생성: hex 코드를 역할과 함께 적으면 색이 그대로 반영된다.
- Midjourney: hex 코드를 직접 못 받으므로 색 이름 + 역할로 적는다. `--style raw`를 붙이면 색이 덜 변한다. HEX 정확 재현은 안 되니 시안용으로 쓰고 정확한 색은 포토샵에서 맞춘다.
- 색이 마음에 안 들면 색 이름이 아니라 **hex 코드만** 바꿔서 다시 생성한다.
