# 제안 유형별 표준 흐름 (Deck Flows)

제안서 전체 목차를 잡을 때 쓰는 골격 3종. 각 장에 어떤 패턴(hrd/change/ms)을 배치하는지까지 정해 둔다.
장수는 기준치다 — 고객 RFP의 목차 지정이 있으면 그쪽이 우선한다.

| # | 장표 | 패턴 |
|---|---|---|
| 1 | 표지 + 제안 개요 (한 장 요약) | — |

| 3 | 진단 결과 요약 — 무엇이 문제인가 | 역량 갭 히트맵 (hrd-3) |

## 흐름 사용 규칙

- RFP에 평가 항목이 있으면, 흐름의 장표 순서가 아니라 평가 항목 순서에 맞춰 재배열한다.
- 고객이 이미 진단·파일럿을 마친 단계면 앞부분 장표를 "기완료 전제" 한 장으로 압축하고 뒷부분을 두껍게 한다.
- 견적 장표는 항상 마지막. 단가 산정 근거(범위·일정)가 앞 장표에서 먼저 보이게 한다.
